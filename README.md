# Hungry Rabbit — концепт сайта

Концепт-сайт развлекательного комплекса **Hungry Rabbit** (Астана, ул. Сейфуллина, 38): ресторан, боулинг на 10 дорожек и караоке «Jimmy ача-ача».

- Сайт: https://hungry-rabbit-astana.vercel.app
- Закрыт от поисковиков (`noindex, nofollow`), в подвале помечен как концепт.

## Что внутри
- Прелоадер, плавный скролл (Lenis), сцены на GSAP ScrollTrigger: разбивка заголовков, параллакс, горизонтальная сцена «пять сценариев вечера», смена фона в блоке караоке, бегущие строки с ускорением от скролла.
- Бросок шара по кеглям на первом экране (запускается, когда кадр в поле зрения), кнопка «Ещё бросок».
- Калькулятор стоимости дорожек, меню с вкладками (10 разделов), форма брони → готовое сообщение в WhatsApp (караоке уходит в WhatsApp «Jimmy ача-ача»).
- Статус «открыто сейчас» по времени Астаны, мобильная нижняя панель, `prefers-reduced-motion`.
